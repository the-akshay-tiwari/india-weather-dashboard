# 🌦️ India Weather Dashboard

A modern and responsive weather dashboard for India built using HTML, CSS, and JavaScript.

## ✨ Features

- 🌍 State & District based weather selection
- 📡 Live weather data using Open-Meteo API
- 🌡️ Current temperature, humidity, and wind speed
- ⏰ Hourly weather forecast
- ☁️ Dynamic weather condition & icons
- 🎨 Modern glassmorphism UI
- 📱 Responsive design
- ⚡ Dynamic DOM rendering using JavaScript

## 🚀 Tech Stack

- HTML5
- CSS3
- JavaScript
- Open-Meteo API

## 📸 Preview

Modern weather dashboard with:
- Live weather updates
- Scrollable hourly forecast cards
- Dynamic weather conditions
- Smooth UI interactions

## 🔧 Future Improvements
